# Proving Ground

Jailbreak the model all you want. The money still can't leave.

AI agents that hold money get prompt-injected: Freysa lost its $47K pot to a function-confusion trick. Proving Ground binds every agent payment to what the human actually authorized, enforced by a NEAR contract, and treats the AI as untrusted.

> Work in progress. Built at NEAR HACKATHON.
